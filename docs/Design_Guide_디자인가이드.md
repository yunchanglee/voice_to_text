**대상**: 프로덕트 디자이너 (UI/UX), 그래픽 디자이너, 안드로이드 프론트엔드 개발자

## 1. 디자인 원칙 (Core Design Principles)

1. **실시간 가독성과 시각적 위계 (Live Visual Hierarchy)**
   - 확정된 문장(`Text-Primary: #0F172A`)과 실시간 임시 인식 문장(`Text-Secondary: #64748B` + 블링크 커서)의 명도 대비를 확실히 두어 음성이 텍스트로 전환되는 과정을 자연스럽게 추적할 수 있도록 합니다.
2. **원터치 컬러 코딩 (Consistent Color Language)**
   - '텍스트 열기'는 시원한 **하늘색(`#0284C7`)**, '공유하기'는 신뢰의 **파란색(`#2563EB`)**, '변환 중'은 주의를 끄는 **레드(`#EF4444`)**, '저장 완료'는 안정감의 **에메랄드(`#10B981`)**로 표준화하여 사용자가 학습 없이도 기능을 즉시 직관합니다.
3. **독립적인 콘텐츠 완결성 (Self-Contained Content)**
   - 외부 뷰어나 텍스트 에디터 설치 여부와 무관하게, 변환 결과를 앱 내부에서 즉시 시원하게 열람하고 복사·공유할 수 있는 모달 경험을 제공합니다.
4. **유연한 반응형 적응성 (Zero-Crush Responsive Layout)**
   - 폴더블, 태블릿, 가로 회전 등 다양한 폼팩터에서 어떤 메타데이터(파일명, 날짜, 소요시간, 파일크기)도 텍스트가 세로로 찌그러지거나 잘리지 않도록 `FlowRow` 및 `no-wrap`을 기본 규칙으로 엄수합니다.

## 2. 디자인 시스템 토큰 (Design Tokens)

### 2.1 컬러 팔레트 (Color Palette)

| **Card (컨테이너)** | `Surface-Container` | `#FFFFFF` | 스크립트 보드, 기록 카드, 인앱 뷰어 모달 |
| **Outline (경계선)** | `Outline` | `#E2E8F0` | 카드, 칩 테두리 및 구분선 보더 |
| **Final Text (확정 본문)** | `Text-Primary` | `#0F172A` | 확정된 본문 텍스트 (최고 명도 대비) |
| **Interim Text (실시간)** | `Text-Secondary` | `#64748B` | 현재 인식 중인 실시간 임시 텍스트 |
| **Muted Text (보조 정보)** | `Text-Muted` | `#94A3B8` | 타임스탬프, 파일 크기, 비활성 텍스트 |

### 2.2 타이포그래피 (Typography)
* **타이머 (`00:15:42`)**: `24sp`(세로) / `32sp`(가로), `ExtraBold`, `font-variant-numeric: tabular-nums` (고정폭)
* **스크립트 본문**: `15.5sp`, 행간 `162% (25sp)`, 문장 간 여백 `12dp`
* **단축 파일명 (`VTT_261102_1437.txt`)**: `14sp` ~ `16sp`, `Bold`
* **메타데이터 칩 텍스트**: `11.5sp`, `SemiBold`, `maxLines = 1`, `softWrap = false` (줄바꿈 방지)

## 3. 화면별 상세 UI 레이아웃 가이드

### 3.1 메인 탭 1: 실시간 변환 화면 (세로모드)

#### A. 대기 상태 (IDLE)
* **상단 앱바**: VoiceToText 로고 + 📁 저장소 폴더 아이콘
* **다국어 선택 칩 바**:
  - `[🌐 자동 감지]`, `[🇰🇷 한국어]`, `[🇺🇸 English]`, `[🇯🇵 日本語]`
  - 선택된 칩: 파란색 틴트 배경 (`#DBEAFE`), 텍스트 볼드
* **중앙 안내 영역**:
  - 부드러운 블루 서클 내 마이크 비주얼
  - 헤드카피: **"재생 중인 소리를 텍스트로 바꿔드려요"**
  - 서브카피: "유튜브, 인강, 팟캐스트 재생 후 시작을 누르세요"
  - 상태 태그: `🟢 다국어 온디바이스 음성인식 준비됨`
* **최근 변환 카드**:
  - 단축 파일명(`VTT_261102_1437.txt`), 소요 시간, 탭 시 해당 파일 상세 이동
* **하단 CTA 버튼**:
  - 대형 레드 버튼: `🔴 변환 시작` (높이 64dp, 곡률 20dp)
  - 하단 안내: `📁 내 파일 › 문서 › VoiceToText 에 자동 저장`

#### B. 변환 중 상태 (RECORDING)
* **상단 스트립**:
  - `📄 VTT_261102_1437.txt` + `[💾 로컬 저장 중]` 배지
* **중앙 실시간 스크립트**:
  - 확정된 문장: 선명한 블랙 본문 텍스트
  - 실시간 인식 중: 연한 회색(`Text-Secondary`) + 레드 블링크 커서
  - 사용자가 위로 스크롤 시 화면 하단에 `[실시간 위치로 ⬇]` 플로팅 알약 버튼 등장
* **하단 제어 독 (Control Dock)**:
  - 경과 시간 타이머 (`00:03:45`)
  - 실시간 오디오 반응형 파형(Waveform)
  - `[⏸ 일시중지]` 버튼 (라이트 그레이 배경) + `[⏹ 종료]` 버튼 (레드 배경)

#### C. 변환 완료 상태 (COMPLETED)
* **상단 카드**:
  - 에메랄드 원형 체크 아이콘 + "로컬에 안전하게 저장했어요"
  - 단축 파일명: `VTT_261102_1437.txt`
  - 3단 통계: 변환 시간 | 문장 수 | 글자 수
* **액션 버튼 그룹**:
  1. **`[📄 텍스트 열기]`**: **하늘색 배경 (`#0284C7`)**, 높이 50dp → 클릭 시 인앱 뷰어 모달 오픈
  2. 2열 보조 액션:
     - **`[📋 전체 복사]`**: 아웃라인 버튼
     - **`[🔗 공유하기]`**: **파란색 배경 (`#2563EB`)**, 흰색 텍스트
  3. **`[🎙️ 새 변환 시작]`**: 뉴트럴 그레이 톤다운 버튼

```
+-------------------------------------------------------+
|  📄 VTT_261102_1437.txt                          [X]  |
|  🇰🇷 한국어  ·  2026.11.02 오후 2:37  ·  1002 B         |
|-------------------------------------------------------|
|  [변환 시작: 2026-11-02 14:37:12 | 언어: 한국어]      |
|                                                       |
|  크레이그는 바버라와 눈을 맞췄다 그는 윙크했다 그녀는   |
|  하지 않았다 심지어 웃지도 않았다 그의 오래된 선물    |
|  상자에는 낡은 편지와 흑백 사진들이 가지런히 정돈되어  |
|  있었다.                                              |
|                                                       |
|  남편에게 달려갔고 그 남자는 일을 하나 끝내고 바위를   |
|  하기 전에 차고에서 맥주를 한잔하고 있었다...         |
|                                                       |
|  [변환 종료: 소요 시간 01:04]                         |
|-------------------------------------------------------|
|  [ 📋 복사 ]    [ 🔗 공유하기 (파랑) ]    [ 닫기 ]     |
|                                                       |
|  =========== (systemBarsPadding 안전지대) ===========  |
+-------------------------------------------------------+
```

* **다이얼로그 스타일**: 라운드 코너 `24dp`, 너비 `92%` (최대 560dp)
* **헤더**: 단축 파일명, 메타데이터 태그, 우측 `X` 아이콘 버튼
* **본문 (Content Scroll)**:
  - 타임스탬프가 배제된 깨끗한 순수 텍스트 문단
  - 폰트 15sp, 행간 160%, 시작/종료 로그는 `Text-Muted` 스타일
* **하단 버튼 바**:
  - 버튼 이름 1줄 고정 (`maxLines = 1, softWrap = false`)
  - `[복사]` (Outline), `[공유]` (Royal Blue `#2563EB`), `[닫기]` (Tonal)
  - **하단 시스템 네비게이션 Safe Inset 필수 적용**: 스마트폰 제스처 바나 3개 소프트키와 버튼이 절대로 겹치지 않음.

### 3.3 메인 탭 2: 변환 기록 화면 (`HistoryScreen`)

#### A. 상단 검색 & 필터
* **검색바**:
  - 높이 `48dp`, 모서리 `24dp` 라운드
  - 텍스트 입력창 수직 중앙 정렬 (`Alignment.CenterVertically`)로 한글 받침 및 영문 디센더 잘림 방지
  - 입력 시 우측에 클리어(`X`) 아이콘 자동 노출 → 클릭 시 검색어 즉시 삭제
* **필터 칩**: `[전체]`, `[오늘]`, `[이번 주]`, `[이번 달]`

#### B. 기록 카드 (`DocumentCard`) & FlowRow 규칙
* **카드 상단**: 단축 파일명(`VTT_261102_1437.txt`), 우측에 `[텍스트 열기(하늘색)]`, `[삭제]` 아이콘
* **본문 프리뷰**: 순수 텍스트 2줄 말줄임(`line-clamp: 2`)
* **메타데이터 FlowRow**:
  - 칩 단위 요소: 날짜(`2026.11.02`), 언어(`🇰🇷 한국어`), 소요시간(`1분 4초`), 파일크기(`1002 B`)
  - **규칙**: 각 칩은 `softWrap = false, maxLines = 1`로 지정되어 어떤 해상도에서도 텍스트가 분할되지 않고, 공간이 부족하면 칩 통째로 다음 줄로 자연스럽게 이동.
* **상태 & 보조 액션 행**:
  - 저장 완료된 경우: `✓ 저장 완료` 배지 (초록색)
  - 저장 중인 경우: `저장 중...` 텍스트 + `[저장 취소]`, `[저장]` 버튼 독립 라인 제공

#### C. 삭제 확인 다이얼로그 (`AlertDialog`)
* 삭제 아이콘 터치 시 팝업: **"변환 기록 삭제"**
* 메시지: "이 기록과 로컬 파일(`VTT_...txt`)을 영구히 삭제하시겠습니까?"
* 버튼: `[취소]`, `[삭제 (레드)]`

### 3.4 가로모드 (Landscape 2-Pane) 화면 가이드

#### A. 상단 System Inset 보호
* 가로 회전 시 스마트폰 상태바(시계, 배터리, 알림 아이콘)와 앱 헤더가 겹치는 문제를 방지하기 위해 최상단 컨테이너에 `Modifier.statusBarsPadding()` 및 `Modifier.displayCutoutPadding()`을 적용합니다.

#### B. 2-Pane 분할 그리드
* **좌측 패널 (36~40%)**:
  - 언어 칩 바, 대형 타이머(`32sp`), 반응형 오디오 파형 바, 제어 버튼 독
* **우측 패널 (60~64%)**:
  - 실시간 스크립트 스트림 또는 기록 상세 스크립트
  - 스크립트 상단 액션 바: `[텍스트 열기 (하늘색)]`, `[복사]`, `[공유 (파란색)]`
  - 메타데이터 태그는 `FlowRow`를 적용하여 분할 너비가 좁아져도 파일 크기(`1002 B`)나 배지가 절대로 세로로 찌그러지지 않음.
* **스크롤 보조 기능**:
  - 사용자가 위로 스크롤하면 우측 하단에 `[실시간 위치로 ⬇]` 플로팅 버튼 자동 활성화.

### 3.5 다국어 텍스트 번역 기능 UI 가이드 (v3.0)

#### A. 실시간 번역 자막 모드 (Live Subtitles)
* **스위치 토글 칩**: 상단에 `[🌐 실시간 자막: 🇺🇸 ➔ 🇰🇷 ON]` 인디고 칩 배치
* **자막 카드 UI (`sub-card`)**:
  - 배경: `#EEF2FF`, 테두리: `#C7D2FE`, 텍스트: `#3730A3`
  - 확정된 외국어 음성인식 문장 바로 아래에 1초 이내로 번역 자막 카드가 스택되어 렌더링.

#### B. 인앱 텍스트 뷰어 3-Way 대조 모달
* **세그먼트 탭**: `[원문]` / `[번역문]` / `[대조 (나란히 보기)]`
* **대조 모드 카드 (`bilingual-card`)**:
  - 상단: 원문 텍스트 (블랙 폰트)
  - 하단: 번역문 카드 (`#EEF2FF` 배경, 인디고 폰트)
* **액션 버튼 연동**:
  - 번역문 탭: `[번역문 복사]`, `[번역문 공유]`
  - 대조 탭: `[대조문 복사]`, `[대조본 공유]`
  - Safe Inset: 하단 네비게이션 소프트키 패딩(`systemBarsPadding`) 동일 적용.

#### C. 오프라인 언어 모델 다운로드 & 진행 모달
* 100% 온디바이스 오프라인 번역 신뢰성을 위해 모델 용량(약 32MB) 및 다운로드 동의 다이얼로그 제공.
* 프로그레스 바: 인디고 컬러 프로그레스 (`#6366F1`)로 번역 진행률 시각화.

## 4. 반응형 및 컴포넌트 검증 체크리스트

| 검증 항목 | 합격 기준 (v2.2) | 비고 |
| :--- | :--- | :--- |
| **가로모드 상태바** | 시계, 와이파이, 배터리 아이콘이 앱 타이틀 및 검색바와 0px도 겹치지 않음 | `statusBarsPadding()` |
